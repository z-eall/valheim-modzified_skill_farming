# ServerSync

`ServerSync.dll` is Jere/Azumatt **ServerSync** (MIT, copyright Tykea, see `LICENSE-ServerSync.txt`), compiled against this Valheim install and **ILRepacked** into `Modzified_Skill_Farming.dll`. Players do not install a separate ServerSync plugin.

Rebuild the DLL from [AzumattDev/ServerSync](https://github.com/AzumattDev/ServerSync) if the game's `ISocket` surface moves again. Do not copy ServerSync `.cs` into the plugin project.
